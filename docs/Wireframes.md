# ERIL - Screen-by-Screen Wireframes

## 1. Dashboard
**Layout:** Sidebar Navigation + Main Content Area
**Components:**
- **Header:** User profile, Notification Bell.
- **KPI Cards:** Total Revenue, Active Leads, Tasks.
- **Recent Activity:** Timeline of recent CRM updates.

## 2. CRM (Contacts)
**Layout:** Sidebar + Main Content
**Components:**
- **Header:** "New Contact" Button, Search Bar.
- **Table:** Name, Email, Company, Tags, Actions.
- **Modal:** Create/Edit Contact Form.

## 3. Sales Pipeline (Kanban)
**Layout:** Sidebar + Main Content
**Components:**
- **Header:** Pipeline Name, View Toggle.
- **Kanban Board:** Columns (Lead, Negotiation, Won).
- **Cards:** Deal Name, Value, Probability.
- **Drag & Drop:** Move cards between columns.

## 4. Workflow Builder
**Layout:** Sidebar + Main Content
**Components:**
- **Header:** Workflow Name, "Save" Button.
- **Canvas:** Visual nodes (Triggers, Actions) connected by lines.
- **Properties Panel:** Edit selected node settings.

## 5. Unified Inbox
**Layout:** Sidebar + Main Content
**Components:**
- **Left List:** Conversation subjects.
- **Middle History:** Message log.
- **Right Compose:** Text input and send button.
